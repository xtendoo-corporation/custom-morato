# Morato Sale Order Mobile Custom

## Descripción
Módulo que simplifica la vista móvil de pedidos de venta y albaranes de entrega para facilitar su uso en dispositivos móviles.

## Funcionalidades

### Pedidos de Venta (sale.order)
- Oculta campos innecesarios en vista móvil
- Añade botón "Confirmar Pedido" para confirmar desde móvil
- Añade botón "Imprimir Pedido" con formato de 58mm
- Optimiza la vista de líneas de pedido para móvil

### Albaranes (stock.picking)
- Oculta campos innecesarios en vista móvil
- Añade botón "Confirmar" para validar albaranes desde móvil
- Añade botón "Imprimir Albarán" con formato de 58mm optimizado
- Optimiza la vista de movimientos para móvil

### Reportes
- Reporte de pedido de venta optimizado para impresoras de 58mm
- Reporte de albarán optimizado para impresoras de 58mm
- Formato compacto ideal para dispositivos móviles

## Instalación
1. Copiar el módulo en la carpeta de addons
2. Actualizar lista de módulos
3. Instalar el módulo "Morato Sale Order Mobile Custom"

## Dependencias
- sale
- stock
- sale_stock
